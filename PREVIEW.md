# Menu Clear — public Safari design preview

This repository serves a **public, fictional-data visual demonstration only**, separate from the private production source repository. It contains no private backend code, authentication credentials or real allergen records.

## Open in Safari
When GitHub Pages is enabled, the address is:

https://leoncresham-arch.github.io/menu-clear-preview/

GitHub repository owner must enable **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)** once. Changes then publish via GitHub Pages.

This is a standalone public UI snapshot based on the shared Menu Clear design, **not a compiled release of the private React application**, and must not be used for allergy decisions. Future automated synchronized releases require a separately authorized mechanism.
